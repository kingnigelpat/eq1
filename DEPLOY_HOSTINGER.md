# Deployment Guide for Hostinger VPS

This guide will walk you through hosting your EQ application on a Hostinger VPS running Ubuntu (20.04 or 22.04).

## Prerequisites
1. **A Hostinger VPS**: Ubuntu 20.04 or 22.04 LTS is recommended.
2. **Access via SSH**: You can connect to your VPS using an SSH client (like Terminal on macOS, PowerShell on Windows, or Putty).
3. **Your Code on GitHub**: Since `git push` failed earlier, you might need to fix that or use FileZilla to upload files. However, Git is preferred.

## Step 1: Connect to your VPS
Open PowerShell or Terminal and run:
```bash
ssh root@your_vps_ip_address
```
(Replace `your_vps_ip_address` with the IP provided by Hostinger).

## Step 2: Upload Your Project Files
### Option A: Via Git (Recommended)
1. Install Git on VPS: `apt update && apt install git -y`
2. Clone your repository:
   ```bash
   git clone https://github.com/kingnigelpat/eq1.git /var/www/eq1
   ```
   *If your repo is private, you may need to generate an SSH key on the VPS and add it to GitHub, or use HTTPS with a token.*

### Option B: Via SFTP (FileZilla)
1. Use FileZilla or WinSCP to connect to your VPS IP with `root` credentials.
2. Create a folder `/var/www/eq1`.
3. Upload all project files from your local machine to `/var/www/eq1`.

## Step 3: Run the Setup Script
I have included a `setup_vps.sh` script in your project.
1. Make it executable and fix line endings (important if uploaded from Windows):
   ```bash
   sed -i 's/\r$//' setup_vps.sh
   chmod +x setup_vps.sh
   ```
2. Run it:
   ```bash
   cd /var/www/eq1
   ./setup_vps.sh
   # It will ask for your domain name (or use IP if no domain).
   ```

This script will automatically:
- Update your server.
- Install Python, Pip, Virtualenv, Nginx, and UFW (Firewall).
- Create a virtual environment and install dependencies.
- Configure Gunicorn to run your app as a service.
- Configure Nginx to serve your app on port 80.
- Set up firewall rules.

## Step 4: Add Environment Variables
Create a `.env` file on the server with your keys:
```bash
nano /var/www/eq1/.env
```
Paste your keys:
```
ELEVENLABS_API_KEY=your_key_here
OPENROUTER_API_KEY=your_key_here
SECRET_KEY=your_random_secret_string
```
Press `Ctrl+X`, then `Y`, then `Enter` to save.

## Step 5: Restart Service
```bash
systemctl restart eq1
```

## Step 6: Verify
Visit `http://your_vps_ip_address` in your browser.

## Detailed Configuration Files
If the script fails or you prefer manual setup, check:
- `gunicorn_config.py`: Settings for the application server.
- `/etc/nginx/sites-available/eq1`: The Nginx config generated by the script.
- `/etc/systemd/system/eq1.service`: The service file generated by the script.
